## 1. Getting Started
1. Clone the repository: `git clone https://github.com/Aryan-Nair-2006/we-kan-code.git`
2. Create virtual environment: `python -m venv .venv` and activate it.
3. Install dependencies: `pip install -r requirements.txt`
4. Run unit tests: `pytest -q`
5. Launch the Streamlit dashboard: `streamlit run frontend/app.py`
